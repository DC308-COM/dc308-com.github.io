# dc308-com.github.io

Source repository for the **DEFCON 308 (Western Nebraska)** website and community blog, hosted on GitHub Pages at [https://dc308-com.github.io](https://dc308-com.github.io) (and [https://www.dc308.com](https://www.dc308.com)).

Built with Jekyll and GitHub Pages, featuring:
- Responsive, terminal-aesthetic dark theme
- Interactive vector & Mermaid diagram viewer ([`assets/diagram-viewer.js`](assets/diagram-viewer.js)) with pan, zoom, and fullscreen capabilities
- RSS feed & sitemap generation
